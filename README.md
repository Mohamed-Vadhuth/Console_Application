# 🏦 Banking Management System

A professional **Console-Based Banking Management System** developed using **Java** as part of the Semester 5 project development.

The project is developed progressively from **Week 1 to Week 12**, with each week introducing new Java concepts, collection frameworks, storage mechanisms, and system improvements.

---

## 📌 Project Overview

The Banking Management System is a console-based application designed to perform basic banking operations such as creating accounts, depositing money, withdrawing money, and checking account balances.

The project starts with simple in-memory storage using `ArrayList` and progressively explores different Java collection frameworks and persistence techniques.

The main purpose of this project is to understand:

- Object-Oriented Programming
- Encapsulation
- Java Collections
- Data searching and sorting
- File handling
- Data persistence
- JSON processing
- Object serialization
- Exception handling
- Modular application design
